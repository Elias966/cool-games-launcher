# Cool Games Launcher 0.2.26

This release includes the locally tested updates since 0.2.20: faster website verification, improved Firefox control and download navigation, and safer version checks for website-installed games.

## Fixed and updated

### Website indexing and Store ordering

- Reuse authenticated website cookies and parallel HTML parsing instead of queuing a browser cookie lookup for every game.
- Read supported pages in bounded batches through Firefox's existing network session when a separate HTTP client is refused.
- Keep rendering fallbacks specific to each page. One incomplete page no longer forces every game on that website through serial browser navigation.
- Process artwork backlogs concurrently and skip cancelled image inference before it reaches the GPU.
- Read complete single-page catalogs, preserve indexing checkpoints, honor server retry times, and avoid overlapping category crawls.
- Keep indexed games visible when a website is paused; clear obsolete website filters and discard stale results when changing Store sort modes.
- Order New using dates published on game webpages, without asking the AI to read every date. Clicking A–Z again reverses the order.

### Firefox and download navigation

- Add Normal browser mode and Installed Firefox with a separate launcher profile under Settings → Browser.
- Installed Firefox uses its own cookies, uBlock Origin and Cookie-Editor. It stays hidden during background work and reveals the same live session for human verification; it does not use the personal Firefox profile.
- Resume automatically after CAPTCHA-triggered control is returned. Explicit manual browsing remains under the user's control.
- Correct viewport screenshots after scrolling, improve startup/session restoration, and recover from closed tabs and changed page observations.
- Learn successful download steps locally and reuse them with current controls across games and restarts.
- Prefer direct downloads in popups and reject torrent/magnet buttons and links, including visual AI clicks.
- Include intermediate host selectors in mirror comparisons, exclude review/filter controls, and rebuild routes from fresh observations.
- Skip third-party file hosts that require CAPTCHA and continue with other hosts. Multipart downloads and measured mirror selection remain supported.

### Website game updates

- Pin updates to the website recorded in the original download receipt. Imported games with an unknown source can recognize known website domains in their folder paths.
- Match imported games only within that source. Unknown or ambiguous identities are not assigned an arbitrary website or game page.
- Try the authenticated fast reader before rendering the saved game page; incomplete, gated or redirected responses fall back to the dedicated Firefox background tab.
- Prevent changed file headers from overriding an older, equal or incompatible game version.
- Separate dated releases and unlabelled large site build numbers from ordinary dotted versions.
- Reject Unity and Unreal engine headers as installed game versions. Use a meaningful EXE FileVersion when a generic ProductVersion such as 1.0 masks the actual build.
- Refresh old version inspections and existing update labels after these corrections, and clear false update offers.
- Recheck a resumed update's original source and offered version before copying saves or replacing the installation. Normal file-host redirects remain supported.

## Validation

- Type checking and all **737 automated tests passed**.
- The exact packaged AppImage was tested in a real launcher session through Library, Store, Downloads, Browser settings and minimize/restore, including a real game-page refresh and local update checks.
- Existing game executable paths, sizes and modification times remained unchanged during testing; no game update installation was performed as a test.
- A seven-game Ankergames verification sample, including 35 cover/screenshot checks, took 7.9 seconds with an empty artwork cache and 2.4 seconds with cached artwork. This is a sample measurement, not an entire-catalog speed claim.

## Known limitations

- Some websites still need slower rendered fallbacks. A full Library sweep can take several minutes, and websites can refuse or require human verification even in an ordinary Firefox session.
- Games without reliable installed version evidence remain unverified. Ambiguous imported game identities remain unlinked rather than receiving a guessed update.
- Intermittent graphics flicker/text clipping remains a known issue; this release does not claim to resolve it.

## Download

Download `Cool-Games-Launcher-0.2.26-x86_64.AppImage`, mark it executable, and run it. The release also includes its `.AppImage.blocks` index for incremental launcher updates and `SHA256SUMS` for verification.
