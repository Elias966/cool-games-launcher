# Cool Games Launcher 0.2.27

- Faster women-cover filtering: overlap up to eight image reads/checks, use small GPU batches, and publish results within 250 ms while work continues. Newly verified games wake the queue immediately. Existing saved scores are reused when toggling the filter or restarting.
- Stop repeated website image verification after its retry budget. Old Anker entries in the affected session had reached 912 attempts; unreadable covers remain hidden and an explicit page refresh permits a fresh check.
- Exclude language flags, icons and avatars from cover selection. Retire incorrectly indexed language-switch URLs (which can redirect in a loop); repair decorative covers on real game pages by reading the page again.
- Recover missing artwork-cache files and invalidate a cover score when its image changes. Report unreadable covers and checks paused during gameplay accurately.
- Fix installed Firefox connection failures with long profile paths. Use short Linux proc paths to reach the existing private socket; keep the dedicated profile and ordinary browser mode.
- Batch page reads through Firefox after fast-reader network failures, then reuse that working transport for later pages. This avoids serial browser navigation for every game on affected hosts.
- Add verification stage timings to the launcher log for slow page reads/image checks.

Validation: the GPU check of 80 real cached covers fell from 2.59 s to 1.41 s, with identical scores on that sample. Batch sizes 1–8 preserved the sample scores; larger batches were excluded. A real installed Firefox using a 175-byte isolated profile path connected and navigated a local test page with navigator.webdriver=false. Real-session Steamrip runs verified six cached-image game pages in 3.33–6.80 s after transport warm-up, with zero per-game browser navigations or model calls. Website response times and CAPTCHA checks can still limit full catalog verification.
